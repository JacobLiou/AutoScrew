# 拧紧来源进阶设定 — 真机对照清单

协议：`#351` 读 / `#301` 写，块 `0xD2–0x14A`（含 `0x13B` 进阶 Bit）。

## 前置

- 设备连接页已应用 IEMD-SD
- 上位机「拧紧来源」页可读写

## 对照项

1. **读回 Bit10**：在设备进阶设定打开「螺丝数量完成，重置数量」→ 上位机「读取当前参数」→ 齿轮弹窗第 11 项应为 ON。
2. **写下 Bit0**：上位机打开进阶，打开「拧紧 OK 后禁止拧松」→ 确认 → 设备弹窗第 1 项应为 ON。
3. **扭矩单位 / 启动条件**：改 `lbf.in` 与「数位 DI 或下压」→ 写设备 → 设备顶部启动条件区一致。
4. **NG 次数 / 最大运行时间**：ON 并改数值后回读一致。
5. **Bit12（第 13 项）**：设备若支持「扫码长度不正确禁止启动」，切换后上位机 Bit12 应跟随；长度阈值字段若 `0x141–144` 恒为 0，本版仅同步开关。

## 回归

- 「下发到设备」仍写入顺序 ID / 螺钉数 / 批头 + 进阶整块。
- 未连接设备时确认弹窗仅落本地 JSON，提示「已写入当前绑定行」。
