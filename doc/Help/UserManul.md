# AutoScrew 用户手册（UserManul）

- 文档版本：v1.0
- 更新时间：2026-08-12
- 适用软件：AutoScrew HMI（当前仓库实现）
- 适用角色：技术员、操作员
- 编写依据：PRD、TODO、当前代码与界面实现

---

## 1. 手册目的与适用范围

本手册用于指导两类用户在当前版本软件中稳定完成产线作业：

- 操作员：按系统引导完成扫码、手动取钉、拧紧、翻面、完工。
- 技术员：完成设备连接、工艺下发、模板维护、MES/LAN配置、NG处理与追溯核查。

当前版本边界（与 PRD V1.4 对齐）：

- 供料为现场手动，软件不做程控供料驱动与调度。
- 单工位、单受控拧紧设备（IEMD-SD）为主路径。

## 2.1 角色权限矩阵

| 功能 | 操作员 | 技术员 |
|---|---:|---:|
| 登录并进入作业台 | ✅ | ✅ |
| 扫码/提交 SN、执行锁附 | ✅ | ✅ |
| NG 后解锁并重打 | ⚠️ 仅紧急解除（需填写理由） | ✅ |
| 标记返修 REWORK 并重打 | ❌ | ✅ |
| 设备连接配置 | ❌ | ✅ |
| 拧紧参数/顺序/来源配置 | ❌ | ✅ |
| 工艺库上传/下发 | ❌ | ✅ |
| 模板编辑与 MES 模板同步 | ❌ | ✅ |
| MES 连接配置 | ❌ | ✅ |
| 历史回顾/追溯分析 | ❌（默认不可见） | ✅ |

## 2.2 职责分工

- 操作员：严格按作业台提示和钉位顺序作业，不越权改参数。
- 技术员：确保设备参数正确、连接稳定、异常可闭环处理，保证可追溯性。

## 3. 快速上手（两角色通用）

1. 启动软件并登录。
2. 确认当前角色（操作员/技术员）与班次账号正确。
3. 进入主界面后检查状态栏无严重错误。
4. 操作员进入作业台准备扫码；技术员先完成开线检查（见第 5 章）。

## 4. 操作员操作指南（SOP）

## 4.1 开工前确认

- 工件、螺钉、工具齐套。
- 电批与工位处于可作业状态。
- 作业台已显示“请输入或扫描 SN”。

## 4.2 标准作业流程

1. 在作业台输入或扫码 SN，点击“提交 SN”。
2. 系统校验 SN 并加载 PN 对应工艺与模板。
3. 看左侧作业进度树，确认当前面与当前钉号。
4. 按中间图板高亮指示，手动取钉并执行锁附。
5. 观察右侧扭矩-角度曲线与底部状态提示。
6. 单面完成后按提示翻面并点击“确认翻面”。
7. 全部完成后出现“本单已完成”，点击“扫描下一 SN”或直接扫描下一单。

## 4.3 状态颜色与含义

- 黄色闪烁：待打钉位（下一目标）。
- 黄色常亮：当前执行中。
- 绿色：已完成且 OK。
- 红色：该钉位 NG。

## 4.4 NG 处理（操作员）

- 常规：联系技术员处理。
- 紧急：可使用“紧急解除”，必须填写原因，系统会写入审计日志。
- 紧急解除后需立即按技术员指示补做确认，禁止直接跳过质量闭环。

## 4.5 常见提示处理

- SN 无效：重新扫码，核对条码枪与标签。
- 作业进行中又扫新 SN：先执行“复位会话”或由技术员处理当前单。
- 提示恢复进度：如确认是同一在制品，选择恢复继续。

## 5. 技术员操作指南（SOP）

## 5.1 开线前检查（建议顺序）

1. 设备连接页检查并测试连接。
2. 工艺库确认当班 PN 的参数槽位与顺序存在。
3. 必要时下发参数与顺序到设备。
4. 拧紧来源确认（主机引导或设备顺序，按现场工艺要求）。
5. MES/LAN 连接参数确认并保存、测试。
6. 试打一单，确认曲线、结果与追溯文件生成正常。

## 5.2 设备连接页

- 关键项：启用、传输方式（TCP/Serial）、主机地址/串口、超时、触发模式。
- 按钮建议使用顺序：保存 → 测试连接 → 应用。
- 站点标识 StationId 需与现场一致，避免跨工位混写数据。

## 5.3 拧紧参数页

- 可读写控制器参数并本地保存预设。
- 从工艺库导入后先核对，再下发设备。
- 重点核对：阶段控制模式、速度、角度、扭矩上下限、扭矩判断开关。

## 5.4 拧紧顺序页

- 维护每颗螺钉执行顺序。
- 可结合导入配置进行排序与验证。
- 下发后建议做最小路径实机验证（至少 1 轮完整顺序）。

## 5.5 拧紧来源页

- 用于配置来源模式与关联参数（涉及 #300/#301 等）。
- 与产线模式一致：主机引导模式下，作业台会按当前钉位驱动流程。

## 5.6 工艺库页（A 层）

- 以产品 PN 为主键管理参数工艺卡与顺序文件。
- 参数区：上传工艺卡、删除槽位、下发参数到设备。
- 顺序区：上传顺序 JSON/Excel、删除顺序、下发顺序到设备。
- 建议：每次换产后执行一次“按 PN 下发”，并记录班次切换时间。

## 5.7 螺钉模板页（C 层）

- 用于编辑产品图、面、钉位、顺序与显示信息。
- 支持本地模板预览与 MES 模板同步。
- 操作建议：先完成面结构，再做钉位精定位，最后统一保存并复核。

## 5.8 MES 连接页

- 支持 Mock、LegacyHttp、ProductKey 模式。
- ProductKey 模式常用于 SN→PN 查询。
- 可配置 LAN 归档根路径，实现无 MES 也可落地追溯归档。
- 改动后执行：保存 → 应用 → 测试连接。

## 5.9 历史回顾页

- 支持按日期、SN、PN、结果筛选。
- 左表查看工单级数据（含 HostMac），右表查看螺钉明细（扭矩、角度、曲线路径）。
- 用于班后复盘、异常追踪与首件确认。

## 5.10 NG 处理（技术员）

- 首选“解锁并重打”。
- 若为返修场景，使用“标记返修并重打”，结果会打 REWORK 标记。
- 处理前确认设备状态与现场安全，处理后复核该钉位最终结果。

## 6. 按场景的标准流程

## 6.1 正常生产（操作员主导）

- 扫 SN → 系统加载 → 手动取钉+拧紧 → 翻面确认 → 完工 → 下一 SN。

## 6.2 换产（技术员主导）

- 工艺库切到目标 PN → 下发参数与顺序 → 首件验证 → 交付操作员批量作业。

## 6.3 断点恢复

- 系统检测到未完成记录时会提示恢复。
- 技术员确认实物状态后决定恢复或重开。

## 6.4 网络异常回退

- MES 不可达时，系统可走本地模板与本地/LAN 归档路径。
- 网络恢复后由后台重传机制继续上报（如已启用）。

## 7. 数据与文件追溯

## 7.1 关键产出

- lock_log_{timestamp}.json：单次作业日志。
- torque_curve_{position}_{timestamp}.csv：单颗曲线文件。
- 本地数据库：作业记录、螺钉明细、审计日志。

## 7.2 典型存储位置

- 本地工作目录：%LocalAppData%\AutoScrew\work\{SN}\
- 审计日志：{DataDirectory}\audit\
- 作业活动日志：{DataDirectory}\activity\
- LAN 镜像（如配置）：{LanShareRoot}\{MAC}\{SN}\
- 模板目录：程序同级 Templates\{PN}\

## 8. 当前版本能力边界（避免误用）

以下属于当前版本未完成或非本期目标，请勿按“已具备”使用：

- 程控供料器自动调度（已取消，现场手动供料）。
- 多工位并行调度。
- 吸头外径与螺钉头自动防错校验完整闭环。
- 任务库 50 组完整产品化能力。
- 全量系统维护功能（#500+）可视化全覆盖。

## 9. 故障快速排查

## 9.1 无法登录

- 检查账号密码与网络。
- 若使用 MIMS，确认数据库可达。
- 需要时联系管理员核查角色映射。

## 9.2 设备无法连接

- 先检查 TCP 地址/端口或串口号/波特率。
- 检查设备启用状态与线缆。
- 点击“测试连接”并查看状态消息。

## 9.3 扫码后不进入作业

- 检查 SN 是否有效。
- 检查是否存在正在进行的旧会话。
- 检查换产弹窗是否被取消导致中止。

## 9.4 曲线未显示

- 优先确认是否已完成一次拧紧动作。
- 若仅曲线控件异常，作业流程通常仍可继续。
