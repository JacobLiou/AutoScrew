## 1. 这套软件在产线上做什么

操作员扫产品序列号（SN）。软件用 **ProductKey** 向现场查询这个 SN 对应的产品料号（PN），再按 PN 加载两样东西：

| 内容 | 放在哪里 | 谁来用 |
|------|----------|--------|
| 拧紧参数、拧紧顺序（工艺库） | 局域网 `{局域网根路径}\process\{产品PN}\` | 换产时写入电批；同 PN 且版本没变则跳过 |
| 作业台引导图（螺钉模板） | 本机程序目录 `Templates\{产品PN}\` | 作业台按面、按钉高亮，告诉操作员打哪一颗 |

取钉由操作员在现场手动完成。软件不驱动供料器。拧紧由电批扳机执行，结果以设备判定为准。完工记录写在本机，并尽量复制到局域网 `{局域网根路径}\{本机MAC}\{SN}\`。1.0 **不把拧紧结果上传到 TAS / 完整 MES**。

安全约束：不要绕过急停、安全门、互锁和扭矩保护。作业进行中不要在参数页、顺序页改设备。

登录后，界面按账号角色显示菜单。管理员与技术员看到的配置菜单相同。

| 菜单 | 操作员 | 技术员 |

操作员登录后只留在作业台，侧栏不展开配置页。

## 3. 操作员

### 3.1 开工前看一眼

- 工件、螺钉、批头已按当班产品备好。
- 作业台提示「请输入或扫描 SN，按 Enter 或点击提交。」
- 状态栏若显示「设备工艺 PN：未下发」，先叫技术员，不要自己改参数。
- 同一种产品连续做时，扫码后一般不会再弹换产窗口。

### 3.2 做一单

1. 在「序列号 SN」框扫码或输入，按 Enter，或点 **提交 SN**。
2. 等待「正在校验 SN…」。校验失败会弹出「SN 校验失败」，核对标签后重扫。
3. 若这台设备还没下发过该 PN，或 PN / 工艺版本变了，会弹出 **换产警告**。
   - 同批次、技术员已交代可以确认：点确认，等「正在换产下发工艺到设备…」结束。
   - 不确定是不是该换产品：点取消。本次扫码中止，叫技术员。取消后提示「已取消换产，请重新扫描 SN。」
4. 若提示「恢复作业记忆」或「恢复未完成作业」：实物确实是这件没做完的产品，选恢复；要整单重做，选否。拿不准时叫技术员看实物。
5. 进入作业后看三块区域：
   - 左侧 **作业进度**：当前面、当前钉号。
   - 中间图：高亮的是要打的钉。
   - 右侧 **扭矩曲线（最近一步）**（可切换扭矩–角度 / 扭矩–时间）和底部 **作业日志**。周期结束后出图；若提示无曲线点，叫技术员查 #751。
6. 按图上的钉手动取钉。日志出现「取钉完成，请按扳机拧紧」后，按电批扳机。不要在软件里找供料按钮。
7. 这一颗 OK 后，图上该钉变绿，进度自动到下一颗。
8. 这一面全部 OK 后，提示翻面。把工件翻到下一面，点 **确认翻面**，再按新的高亮继续。
9. 日志出现「本单全部完成」后，扫下一件 SN。

钉位颜色：

| 颜色 | 含义 |
|------|------|
| 黄色闪烁 | 下一颗待打 |
| 黄色常亮 | 正在打 |
| 绿色 | 这一颗 OK |
| 红色 | 这一颗 NG，作业已暂停 |

### 3.3 作业进行中不要换 SN

正在做某一件时，再扫别的 SN 会被拦住，提示先 **复位会话**。复位会保存当前进度，之后扫同一 SN 可以恢复。不要在没做完时直接扫下一件。

### 3.4 NG 时操作员怎么做

作业暂停，标题为「拧紧 NG — 作业已暂停」或「设备 NG — 请退出挂起」。

- 常规：停手，叫技术员。技术员用 **解锁并重打**，或在返修时用 **标记返修并重打**。
- 设备故障、暂时不能打：点 **退出作业（挂起）**。修好后扫 **同一个 SN** 恢复，不要开新单。
- 只有现场明确授权的紧急情况才用 **紧急解除…**。必须填写解除理由，内容会连同操作员身份写入审计。紧急解除不是跳过质量确认。

操作员没有「标记返修并重打」。该按钮只给技术员。

## 4. 技术员

建议按下面顺序开线。前一步没过，不要直接交给操作员。

### 4.1 开线检查

1. **设备连接**：地址、端口正确，点测试连接，再点应用。同一时间只允许本软件连接控制器（默认端口 502）。关掉厂家演示软件和其它上位机。
2. **MES 连接**：模式为 ProductKey，保存、应用、测试连接通过（见 4.2）。
3. **工艺库**：当班产品 PN 下能看到参数槽和拧紧顺序，根路径指向局域网 `process`（见 4.3）。
4. **螺钉模板**：本机 `Templates\{该PN}\` 里有对应的作业台文件（见 4.4）。工艺库在网上，引导图仍在本机，两处都要有。
5. **拧紧来源**：工位设一次即可（见 4.5）。换产不会自动改来源。
6. 用一颗真实 SN 走完首件：能查出 PN、换产写入电批、图上钉位正确、拧完有曲线、本机和局域网都有该 SN 的记录。

### 4.2 MES 连接（ProductKey）

菜单：**系统 → MES连接**。

产线使用：

| 项 | 填写 |
|----|------|
| MES 模式 | **ProductKey（getProductInfo）** |
| MES 基址 | `https://zuhaip.molex.com:9607/`（末尾保留 `/`） |
| 接受任意服务端证书 | 现场证书不是公有 CA 时保持开启 |
| 超时（秒） | 100 |
| 探测 SN | 一颗真实在制品 SN，专供「测试连接」 |
| 局域网根路径 | UNC，例如 `\\server\share\AutoScrew` |

API Key 只给 LegacyHttp，ProductKey 不用填。

改完后顺序固定：**保存配置 → 应用 → 测试连接**。只保存不应用时，当前这次运行仍用旧配置。

测试连接的结果：

- 探测 SN 查到数据：连接正常。
- 提示找不到该容器、或没有产品信息：说明主机可达，但这个 SN 没有数据。换一颗真实 SN 再测。
- 超时、证书错误、连不上：产线还不能扫码，先查网络和基址。

ProductKey 只负责 SN→PN。它不下载工艺，也不上传拧紧结果。SN 必须是可用状态（现场返回 Status 为 1 且未 Hold），否则作业台会拒绝该 SN。

局域网账号不在这个页面上填。连接使用内置服务账号，口令放在本机程序配置 `AutoScrew:LanSharePasswordAes256`。口令缺失或错误时，工艺库和归档都会连不上共享，软件会改用本机目录，看起来像「网上的工艺不见了」。

### 4.3 工艺库（拧紧参数和顺序）

菜单：**设备配置 → 工艺库**。

工艺库根路径：

- 已配置局域网根路径：`{局域网根路径}\process\`
- 未配置或连不上：本机数据目录下的 `process\`

每个产品一个文件夹：

```text
process\{产品PN}\
  product.json
  screws\00.txt
  screws\01.txt
  sequences\01.json
```

`product.json` 里的 `updatedUtc` 是版本。同一 PN 若这个时间变了，下一件扫码仍会要求重新写入电批。

日常操作：

1. 选择或输入 **产品 PN**，点 **加载产品内容**。
2. **拧紧参数** 页：上传工艺卡 TXT。槽位 `00` 对应设备参数 ID `1`，`01` 对应 `2`，以此类推。
3. **拧紧顺序** 页：上传顺序 JSON、TXT 或 Excel。顺序 ID 在页面填写；TXT 与 Excel 都要求对应工艺卡槽位已经在库里。
4. 需要立刻写进电批时，点 **下发参数到设备**、**下发顺序到设备**。平时也可以不在这里下发：操作员扫到新 PN 并在换产警告里确认后，作业台会覆盖写入参数和顺序。
5. **删除选中槽位 / 删除选中顺序** 只删工艺库文件，不改电批里已经写下的内容。

从电批把调好的参数收回库：

1. **拧紧参数** 页从设备读出，导出工艺卡 TXT。
2. **拧紧顺序** 页从设备读出，导出顺序 Excel 或 TXT。
3. 回到工艺库，选对产品 PN 再上传。

上传前确认文件进的是该产品目录，不要把 A 产品的卡传到 B 产品下。

### 4.4 螺钉模板（作业台引导图）

菜单：**螺钉模板**。

这是给操作员看的产品图、面和钉位，不是电批里的扭矩参数。1.0 产线从 **本机** `Templates\{产品PN}\{产品PN}.product-template.json` 读取。ProductKey 不会从 MES 拉这个文件。页面上的「MES 同步」在生产模式下不可用，不要依赖它。

新建或修改：

1. **新建产品**，产品 PN 必须与 ProductKey 返回的 PN、工艺库文件夹名一致。
2. **添加面**，设置作业顺序。多面产品按这个顺序引导翻面。
3. **加载底图**。需要和图片对齐时，先点 **画板=底图像素**，再在图上点钉位。
4. 保存。文件名保持 `{产品PN}.product-template.json`，放在该 PN 文件夹内。
5. 换产或试打前，用「预览所有本地模板」确认这个 PN 在列表里。

作业台找不到该文件时，扫码会停住，提示模板不存在。工艺库里已有参数也不能代替这张图。

### 4.5 设备连接、参数、顺序、来源

**设备连接**

- 填主机地址、端口、工具号，确认已启用。
- 顺序：**测试连接 → 应用**。应用后保持这一条连接。
- 作业拧紧过程中，参数 / 顺序 / 来源页的下发会因设备忙而不可用。等这一颗打完再改。

**拧紧参数 / 拧紧顺序**

- 用于单台调试：从设备读取、修改、下发，或从工艺库导入到本机后再核对。
- 从工艺库导入只改本机预设，不会自动写电批。要写电批，用工艺库的下发按钮，或走作业台换产确认。
- 正式换产以工艺库为准，不要只改本机预设就交给操作员。

**拧紧来源**

- 每个工位设置一次，例如手动来源。全班产品共用，除非工艺明确要求改。
- 1.0 换产不会按 PN 自动改来源。

### 4.6 换产时技术员要做什么

同一种产品连续生产：操作员只扫 SN。软件发现 PN 和工艺库版本都没变，就不再写电批。

换成另一种产品，或同一 PN 的工艺库更新过：

1. 事先确认工艺库里该 PN 的参数和顺序齐全，本机螺钉模板也在。
2. 电批上当前没有正在拧的钉子。
3. 操作员（或技术员在作业台）扫新 SN。
4. 弹出换产警告后点确认。软件按工艺库覆盖写入参数和顺序，成功才进入引导。
5. 首件看钉序、扭矩和曲线。首件不对，不要放行批量。

点取消，或下发失败：这一次 SN 作废，可重扫。工位上记住的「已下发 PN」不会被这次失败改掉。

作业台状态栏的「设备工艺 PN」就是当前电批已按下的产品。

### 4.7 NG、返修、挂起

| 按钮 | 谁来点 | 作用 |
|------|--------|------|
| 解锁并重打 | 技术员 | 解除这一颗 NG，按原钉重打 |
| 标记返修并重打 | 技术员 | 同上，并且本 SN 结果标记为 REWORK |
| 退出作业（挂起） | 操作员或技术员 | 保存进度并离开。修好后扫同一 SN 恢复 |
| 紧急解除… | 操作员 | 必须填理由并记审计。仅紧急情况 |
| 复位会话 | 作业未结束却要离开时 | 保存进度。之后扫别的 SN 前应先复位 |

处理前确认急停和互锁仍有效，电批不在拧紧行程中。处理后看该钉最终是 OK 还是仍然 NG，再决定能否流到下一面。

### 4.8 历史、日志、高级文件

**拧紧结果**（设备配置 → 拧紧结果）：查看最近一次拧紧周期的扭矩/角度摘要，并排显示扭矩–角度与扭矩–时间曲线（与作业台同源，周期结束后刷新；中间可拖拽调宽）。本页只观察，不做试打。

**历史回顾**：按日期、SN、PN、结果查本机作业。左侧是整单，右侧是每一颗的扭矩、角度和曲线路径。用于首件、末件和 NG 复查。

**日志/审计**：查谁改了 MES、谁确认了换产、谁做了紧急解除。

**高级文件**：维护局域网或本机上的工艺、模板文件。进入受限目录前按页面要求解锁。不要在作业进行中替换当前 PN 的工艺文件。

**设备记录**（生产履历、异常履历、警告履历、按钮履历）：查控制器侧记录，和上位机历史回顾互补。

## 5. 两种角色怎么交接

### 班前

技术员完成 4.1，用一颗真实 SN 做首件，确认「设备工艺 PN」正确，再把工位交给操作员。

### 班中

操作员只使用作业台：扫码、手动取钉、按扳机、翻面、完工。出现 NG、换产窗口拿不准、或扫码失败，停下来叫技术员。

### 班后

技术员在历史回顾里抽查首件、末件和 NG。需要时到局域网 `{MAC}\{SN}` 核对曲线和 `lock_log`。

## 6. 记录放在哪里

| 内容 | 位置 |
|------|------|
| 本机作业文件（曲线 CSV、`lock_log_*.json`） | 数据目录下的 `work\{SN}\`。数据目录未另配时，在 `%LocalAppData%\AutoScrew\` 一带 |
| 局域网作业副本 | `{局域网根路径}\{本机MAC}\{SN}\`。MAC 形如 `AA-BB-CC-DD-EE-FF` |
| 工艺库 | `{局域网根路径}\process\{产品PN}\` |
| 作业台模板 | 程序目录 `Templates\{产品PN}\{产品PN}.product-template.json` |
| MES 配置 | 数据目录 `mes-settings.json`（由 MES 连接页保存） |
| 本工位已下发的 PN | 数据目录 `station-process-state.json` |
| 审计 | 数据目录 `audit\` |

局域网复制失败不会挡住当前这件做完，但班后应查共享是否真有该 SN 文件夹。没有的话，先看 MES 页的局域网根路径，再看本机口令配置和共享权限。

## 7. 扫码后软件实际走的路径

便于技术员判断「卡在哪一步」：

1. ProductKey 查询 SN，得到 PN。查不到、PN 为空、或 SN 不可用：停在校验失败。
2. 用本机螺钉模板找这个 PN。没有模板文件：停在加载配方，工艺库有数据也不继续。
3. 比较工艺库里的 PN、`updatedUtc` 和本工位上次下发记录。
   - 相同：直接作业。
   - 不同或库中没有该产品：换产警告。确认后覆盖写入电批参数和顺序。
4. 按模板高亮钉位。操作员手动取钉，按扳机。设备返回 OK/NG。
5. 全部钉 OK 后，本机留下记录，并尝试复制到局域网。不上传 TAS。

## 8. 1.0 不要当成已有功能

- 自动供钉、供料器调度。取钉始终人工。
- 把拧紧结果上传到 TAS 或完整 MES。ProductKey 只查 SN→PN。
- 用「MES 同步」从生产 MES 下载或上传螺钉模板。
- 按产品自动切换拧紧来源。
- 视觉定位、多工位同时调度。
- 在 MES 上报里区分面号、位号（本机作业进度已经按面和钉区分，出站字段未按此上报）。

## 9. 常见问题

| 现象 | 先查 |
|------|------|
| 登录失败 | 账号密码；现场若走 MIMS，查数据库是否通 |
| 设备连不上 | 地址和端口、网线、是否已有别的软件占用 502。测试连接后再应用 |
| 测试连接失败 | 模式是不是 ProductKey，基址是否为 `https://zuhaip.molex.com:9607/`，是否已点应用 |
| SN 校验失败 | 条码是否完整；该 SN 在 ProductKey 中是否有 PN，且状态允许作业 |
| 提示工艺库没有这个 PN | 文件夹名是否等于返回的 PN；局域网是否连上。连不上时软件读的是本机 `process` |
| 提示找不到模板 | 本机 `Templates\{PN}\{PN}.product-template.json` 是否存在。与工艺库不是同一目录 |
| 换产后电批参数不对 | 工艺库 TXT / 顺序是否传错产品；槽位 00 对应设备 ID 1 |
| 扫了新 SN 却没换参数 | 同 PN 且 `updatedUtc` 未变会跳过写入。工艺改过但清单时间没变时，更新工艺库后重扫 |
| 作业中扫下一件被拒绝 | 先 **复位会话**，或把当前件做完 |
| 曲线空白 | 先确认这一颗已经拧完。仅曲线控件初始化失败时，作业仍可继续，以日志和历史里的曲线文件为准 |
| 局域网没有 SN 文件夹 | 根路径、共享权限、`LanSharePasswordAes256`。本机 `work\{SN}` 仍应有文件 |
| 下发时提示设备忙 | 等当前拧紧周期结束，不要在打钉时写参数 |

更细的控制器联调现象见 `doc/IEMD_SD_SINGLE_DEVICE_SOP.md`。那份文档给维护人员，不是操作员日常步骤。
