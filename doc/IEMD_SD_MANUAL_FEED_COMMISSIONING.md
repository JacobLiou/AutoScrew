# IEMD-SD 手动供料联调路径

| 版本 | 日期 | 状态 |
|------|------|------|
| 0.1 | 2026-06-26 | 对齐设备式三页 HMI |

**前置**：Modbus TCP 已连接（「设备连接」页应用并重连）。

## 最小联调路径（HostGuided）

按 **参数 → 来源 → 作业台** 顺序（顺序页在 DeviceProgram 模式下必需）：

1. **设备连接** → 应用并重连
2. **拧紧参数**：刷新 #160 列表 → 选中 ID → **导入选中 (#150)** → 确认扭矩/阶段
3. **拧紧来源**：切换方式 = **手动** → 写 #300/#301 → 读 #350 确认 CC=0；产线模式选 **上位机引导**
4. **作业台**：扫 SN → 确认 #302 使用 Recipe 中存在的 `controllerParameterId`

## DeviceProgram 扩展路径

1. **拧紧参数** → **拧紧顺序**（步骤绑定参数 ID）→ **拧紧来源**（绑定顺序 + 写 #300/#301）
2. 产线模式选 **设备顺序程序** → **激活 #303** 或「一键部署」
3. 作业台不再发 #302，由 #301+#303 驱动

## 常见协议错误

| 现象 | 处理 |
|------|------|
| #150 code 3 | 该 ID 未在控制器配置；用 #160 列表确认 |
| #100 code 18 | 扭矩超工具规格；降低目标扭矩 |
| #302 code 1 | #300 切换方式须为手动 (CC=0) |
