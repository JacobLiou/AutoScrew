# 数据模型与追溯契约（草案）

在项目早期冻结**最小必选字段**与 **SN–螺钉位**绑定规则，减少 MES / 上位机后期返工。具体报文格式、URL、队列等由公司与 IT 批准后替换本文「待定」占位。

权威需求摘要见 [SPEC.md](SPEC.md)（§ 功能与工艺 §6 数据上云、§ 批验收 § 软件「按 SN/螺钉位置保存」）。

---

## 1. 总则

| 项 | 建议 / 占位 |
|----|-------------|
| 数据生产者 | 智能电批/拧紧控制器、供料模组（故障码）；上位机聚合 |
| 落盘顺序 | 建议：**本地可追溯落盘成功**后再异步上传 MES/服务器 |
| 时间 | 推荐使用 **UTC 存、本地时区展示**；工控机启用 **NTP** |
| 配置版本 | 每次任务绑定 **recipe_id / program_version**，便于复现 |

MES 集成风险见 [RISK_REGISTER.md](RISK_REGISTER.md) R05/R07。

## 2. 曲线与时间序列

### 2.1 采样率（待数值确认）

| 项 | 建议 |
|----|------|
| 目标下限 | ≥ **833 Hz** 仅作对标参考（业界数据集常见量级）；**以电批/controller 能力与验收判定需求为准**，在 α 与供应商共同签字 |
| 对齐 | 扭矩、角度、时间戳同源时钟；注明是否控制器内插 |

### 2.2 原始通道（每采样点）

| 字段 ID | 含义 | 类型 | 必选 |
|---------|------|------|------|
| `t_ms` | 相对或绝对毫秒时间戳 | 整数或浮点 | 是 |
| `torque_nm` | 扭矩（Nm 或合同约定单位） | 浮点 | 是 |
| `angle_deg` | 角度（度） | 浮点 | 是 |
| `rpm` | 转速（若可得） | 浮点 | 否 |

### 2.3 派生与摘要（可减轻 MES 体积）

按需增加，例如：`torque_peak`、`angle_at_peak`、`strategy_step_index`、`abort_code`。**判定码**必须与 HMI NG 文案可映射。

## 3. 事件与子记录粒度

推荐 **两级结构**（实现可flatten为宽表）：

| 层级 | 说明 |
|------|------|
| **会话 / 工单** | 一次扫码开工到完工：`work_session_id`、`sn`、`pn`、`recipe_id`、`operator_id`、`station_id`、`started_at`、`ended_at` |
| **单颗螺钉** | 每条拧紧一条子记录：`screw_sequence_no`（或图位 **NO**）、`result`（OK/NG）、`ng_category`（漏锁、滑牙、浮锁等）、可选 `curve_ref` |

**状态机占位**：`idle` → `picked` → `pre_run` → `run` → `judging` → `ok`/`ng` →（可选）`human_override`。与报警逻辑对齐 [SPEC.md](SPEC.md)。

## 4. SN 与螺钉位绑定规则

| 规则 | 说明 |
|------|------|
| **SN 来源** | 条码/ RFID 扫码；校验长度与前缀（待定） |
| **位号** | 与 PN 图示 **NO/坐标**一致（参见 SPEC § 软件开发需求方案：闪烁提示实现） |
| **顺序防错** | 是否强制执行顺序螺钉表：若为是，跳过记为未完成并触发 SPEC 所述报警 |
| **错料防错** | Recipe 内含 **螺钉料号/编码**；与供料站位绑定（待定） |
| **返修** | 复检与原 SN / 重工工单关联方式：**待定**（避免与量产混淆） |

## 5. 上传最小必选集（占位表）

MES/服务器 **最小必选**字段建议如下；IT 可增加列但不宜删减键字段。

| 字段名（建议） | 含义 | 类型 | 必选 |
|----------------|------|------|------|
| `station_id` | 工位 | 字符串 | 是 |
| `sn` | 产品序列号 | 字符串 | 是 |
| `pn` | 料号 | 字符串 | 是 |
| `screw_index` | 螺钉序号/位号 | 整数 | 是 |
| `result` | OK / NG | 枚举 | 是 |
| `started_at` / `ended_at` | 拧紧起止 | ISO8601 | 是 |
| `recipe_id` | 工艺版本 | 字符串 | 是 |
| `torque_target` / `torque_actual` | 目标/实际（或峰值） | 浮点 | 按工艺 |
| `angle_actual` | 实际角度（或关键角度） | 浮点 | 按工艺 |
| `curve_ref` | 曲线文件 URI 或内嵌 ID | 字符串 | 按合同 |
| `ng_code` | 判定细分码 | 字符串 | NG 时必选 |

传输方式（REST、MQ、DB 中间表、厂商中间件）**待定**；认证（TLS、API Key、域账号）**待定**。
