## 产线现状（需求书）

- 多型号螺钉混用，员工需准备大量螺钉至工位，**放置管控困难**。
- 频发：**漏装、未打紧、用错螺钉**；存在客诉与月度问题记录。
- 无磁螺钉需**手动点数 + 镊子/手动取放**，效率与品质风险并存。
- 工艺上存在可取消的冗余动作，单颗可节省约 **5 s**（依实际工艺）；数钉/镊子取放取消约 **4.5 s/颗**；手动锁附改智能锁附约 **7.5 s/颗**（需求书表述，以实测为准）。

## 功能与工艺要求（需求书「要求」1–6 +「其他」7–8）

1. **智能螺丝刀**：软件控制扭矩，力矩可**分段**控制；可调锁附**转速 / 角度 / 时间**等。
2. **气吸取钉**：支持**预锁附、锁附、紧固**；锁附**曲线实时显示与判定**（示意图见源表）。
3. **任务管理**：可预存 **50 组**任务项，支持**一键下发**。
4. **SN 驱动工艺**：扫描产品 **SN**，软件自动调取对应 **PN 模板**；**图片**显示待上螺钉位置（示意图见源表）。
5. **异常报警**：漏装、用错螺钉、未打紧、**入牙倾向**等异常需提示。
6. **数据上云**：安装数据自动上传至公司指定服务器。
7. **歪斜判定**：螺钉轴线与取钉机吸嘴/夹爪中心轴线夹角超过 **3°** 即判歪斜。
8. **吸头尺寸**：吸头外径 ≤ 螺钉头外径 **+0.6 mm**。

## 批验收标准（摘录自「智能锁附系统验收标准」）

### 功能 / 硬件 / 软件

| 模块 | 检验标准（摘要） |
|------|------------------|
| 功能 | 吸取螺钉、智能锁附、智能报警 |
| 硬件 | 手持式主体；多吸头、多力矩头匹配、**快拆更换**；尖端对地电阻 **<10 Ω**；尖端电流 **<10 mA**、尖端电压 **<10 mV**；电源 **AC220V±10%，50 Hz** |
| 软件 | 对接 **MES**；扫 SN 调取文档；界面状态色（待上黄闪、OK 绿、进行中黄、NG 红）；**扭矩+角度双控**、曲线、浮锁/滑牙/斜锁/卡钉/漏锁检测；批次任务一键下发、可上传图片；按 **SN/螺钉位置** 自动保存数据 |

### 技术参数（关键 KPI）

| 指标 | 要求 |
|------|------|
| 掉钉率 | ≤ **0.3%** |
| 螺钉歪斜比率 | **<1%** |
| 扭矩精度 | ≤ **±3%** |
| 重复性（金属件多次拧紧） | ≤ **±1%** |
| 动态扭矩波动 | ≤ **±3%** |
| 线性误差（全量程多点） | ≤ **±1.5%** |
| 锁附角度精度 | ≤ **±5°** |
| 角度-扭矩斜率 | ≥ **0.5 N·m/°** |
| 过扭保护 | ≤ **110%** 设定值 |
| 最高 / 最低转速 | ≤ **2000 rpm** / ≥ **20 rpm** |
| 主轴/齿轮箱寿命 | ≥ **100 万次** 锁附 |
| 外观 | 不破坏螺钉外观，不掉金属碎屑等异物 |
| 运行稳定性 | 使用期间无影响主要功能的**关键性故障** |
| 安全 | 符合 **EHS** 要求 |

### 环境与试用

- 运行环境：**23±3℃**；相对湿度 **30%–70%**。
- **7 天**生产试验运行，软硬件无关键性故障；异常则验收期顺延；试运行需满足上述技术参数；**开放端口**配合 MES 整合；资料含操作/维护说明书、电气原理图与接线图等。

## 供应商会议记录（Sheet1 摘要）

- 供料与垂直取钉、吸钉横向锁附验证通过；后续消音至 **50 dB** 目标。
- 锁附与手动扭力对比、松脱力相当；需收集基础数据设定上下限。
- 改善项：**仅换吸嘴**、螺纹改**卡扣快换**；供料器缩小；主机空间约 **25×17×12 cm → 缩减 1/3～1/2**；吸头寿命 **≥3 年**；电批寿命/校正策略与商务条款对齐。
