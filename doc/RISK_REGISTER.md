# 风险登记（智能锁附系统）

与 [SPEC.md](SPEC.md)（V1 需求与验收）及 [DATA_AND_TRACE.md](DATA_AND_TRACE.md)（数据契约）对照使用。**不替代合同或正式 FMEA**，用于项目周会与里程碑跟踪。

## 使用说明

| 项 | 说明 |
|----|------|
| **何时更新** | 周例会、α/β 阶段入口、试运行前、MES/接口变更评审后 |
| **维护人** | 指定单一 Owner（可轮换）；关闭项保留记录 |
| **与问题关系** | 重大异常建议另建 corrective action 编号并在「备注」中引用 |

## 升级触发（建议）

试运行（SAT）前，凡 **严重程度 ≥ 高** 且 **缓解未落实** 的项，须在阶段评审中单列决策（接受残余风险须书面签字）。
