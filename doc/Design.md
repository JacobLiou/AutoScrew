             │

# 流程引擎（核心能力）

------

## 4.1 状态机定义（必须）

```
Idle
→ WaitingSN
→ LoadingProcess
→ Executing
→ Error
→ Finished
```

------

## 4.2 Step执行流程

```
加载Step
→ 选择Feeder
→ 选择Tool
→ 控制电批执行
→ 获取数据
→ 判定结果
→ 更新UI
```

------

## 4.3 异常控制

| 类型     | 处理      |
| -------- | --------- |
| NG       | 重试/跳过 |
| 设备异常 | 停机      |
| 通讯失败 | 重连      |

------
