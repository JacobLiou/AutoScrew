# 驱动资料分析与总结（driverAna.md）

## 1. 资料结构与用途说明

本资料包包含三类内容：
- **Help 文件夹**：包含操作演示动图及 HTML 索引页，直观展示控制器常用功能、通讯流程、参数切换、固件升级等。
- **Demo 工程**：三套 Winform 示例程序，分别演示通过 Modbus TCP、FTP 等方式与电批控制器通讯，获取拧紧结果、报表、曲线等。
- **PDF 手册**：详细介绍 IEMD-SD 系列 10.1 寸控制器的硬件、界面、参数设置、通讯协议（Modbus/FTP）、寄存器定义及典型应用流程。

---

## 2. Help 文件夹内容梳理

- `ScrewHelp.html` 为主索引页，左侧为功能目录，右侧展示对应动图。
- 动图内容分为：
  - **Quick Start**：快速启动流程演示
  - **Communication**：
    - Get Result
      - Automation：自动工位拧紧并获取结果
      - Manual station：手动工位拧紧并获取结果
    - Get Report Info
      - Modbus TCP #750：读取报表
      - Modbus TCP #751：读取曲线
      - FTP：通过 FTP 读取曲线
    - Switch Param ID：切换参数组（#302）
  - **Update firmware**：固件升级流程（10.1/4.3 两种机型）

> 这些动图可作为开发/调试/培训时的操作参考，帮助理解控制器与上位机的典型交互流程。

---

## 3. 三个 Demo 功能简述

- **ScrewDriverC# Winform(GetResultStatus)**
  - 演示如何通过 Modbus TCP 协议，自动/手动触发拧紧动作，并读取运行结果（OK/NG、扭矩、角度等）。

- **ScrewDriverC# Winform(ModbusTCP)**
  - 演示通过 Modbus TCP 协议，读取报表（750）、曲线（751）等数据。

- **ScrewDriverC# Winform(ModbusTCP+FTP)**
  - 在 Modbus TCP 基础上，增加 FTP 通道，演示如何通过 FTP 下载曲线数据，适用于大数据量/历史数据场景。

> Demo 工程代码可直接复用或参考，快速实现与控制器的数据交互。

---

## 4. PDF 手册重点梳理

- **硬件与界面**：详细介绍控制器硬件结构、显示界面、参数设置方法。
- **通讯方式**：
  - 支持 Modbus TCP/RTU、FTP 等主流工业通讯协议。
  - 典型流程：
    1. 上位机通过 Modbus TCP 发送“启动拧紧”命令
    2. 控制器执行动作，状态/结果通过寄存器反馈
    3. 上位机读取结果寄存器，或通过 FTP 下载详细曲线/报表
- **寄存器定义**：
  - 主要功能寄存器如：启动/停止、状态、结果、报表（750）、曲线（751）、参数切换（302）等
  - 每个寄存器地址、数据格式、读写权限详见手册
- **典型应用流程**：
  - 自动/手动工位拧紧流程
  - 结果判定与数据采集
  - 参数组切换与固件升级

---

## 结论

本资料包内容齐全，覆盖了从硬件、界面、通讯协议到上位机集成的全流程。建议：
- 开发前先通读 PDF 手册，明确寄存器与通讯流程
- 结合 Demo 工程快速验证通讯
- 遇到具体操作疑问时，参考 Help 动图
